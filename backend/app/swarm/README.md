# Kairo Collective Intelligence & Swarm Reasoning Engine (Task 64)

## Overview
The **Kairo Collective Intelligence & Swarm Reasoning Engine** coordinates multiple specialized agents, reasoning processes, and empirical evidence toward complex shared objectives.

### Critical Invariants
- **AGENT AGREEMENT != TRUTH**
- **CONSENSUS != FACT**
- **MAJORITY != EVIDENCE**
- **AGENT CONFIDENCE != CERTAINTY**
- **COLLECTIVE OUTPUT != VERIFIED REALITY**
- **CAPABILITY != AUTHORIZATION**
- **EXTERNAL CONTENT != INSTRUCTION**
- **AGENT MESSAGE != AUTHORITY**
- **UNKNOWN != HEALTHY**
- **MORE AGENTS != BETTER REASONING**
- **MINORITY OPINION != ERROR**

## Swarm Topologies
1. **STAR**: Central coordinator delegates to independent specialists, then synthesizes.
2. **PIPELINE**: Staged linear handoffs with validation between steps.
3. **DEBATE**: Structured adversarial dialectic between thesis and antithesis.
4. **HIERARCHICAL**: Coordinator delegates to sub-coordinators and worker specialists.
5. **PEER_TO_PEER**: Decentralized cross-audited peer consensus.
